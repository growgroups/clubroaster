# ClubRoster

Interactive HTML concept for the Pizzey Park Netball Club umpire rostering pilot.

## Prototype scope

The static concept demonstrates:

- full-season bulk fixture import across associations, age groups and divisions
- intelligent column mapping and fixture-change review
- umpire profiles from junior to senior officials
- guardian-linked junior experience
- recurring availability and preferences
- AutoRoster allocation and explainability
- hard and soft scheduling rules
- exception management and minimum-change roster repair
- game-day check-in and emergency replacement
- match-fee approval concept
- season demand, fairness and shortage reporting
- role-based navigation for administrators, coordinators, mentors, finance, supervisors, umpires, guardians and auditors
- accessibility controls including larger text and simplified views
- audit trail and concept architecture

## Run locally

Open `index.html` directly in a browser. No build step is required.

## GitHub Pages

This repository is designed to publish from the repository root. After the prototype PR is merged, GitHub Pages can be enabled from the `main` branch root when public deployment is approved.

## Concept-only boundary

- Synthetic demonstration data only.
- No authentication or production backend.
- No real child, guardian, payment or sensitive personal data.
- No real messaging, payroll or payment execution.
- The prototype does not determine whether an umpire is an employee, contractor or volunteer.
- Child-safety, privacy, consent and association rules must be formally validated before production release.
